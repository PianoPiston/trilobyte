## Honest limits

- No Context.dev monitor resource, ID, remote schedule, webhook or monitor-side run history is implemented. Live retrieval uses Context.dev Web Scrape/Search; polling, snapshots and observations are local to DriftCI.
- No genuine external page change occurred between the first baseline and validation. Diff behavior is verified by deterministic changing-response tests, while the live service correctly shows zero observations until a source actually changes.
- Search highlights were empty for several live results. The UI omits empty summaries rather than filling them with generated prose.
- Live OSV reports many real advisories for the intentionally outdated Next.js example. This is noisy but source-backed; results are not deleted to improve the demo appearance.
- Selective source and OSV coverage are bounded and may be partial. Unread files or unchecked packages are not certified safe.
- No authoritative Context.dev account dashboard reconciliation has been performed here. Only API receipts and the local ledger are recorded.
