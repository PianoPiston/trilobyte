# DriftCI pitch

## Punchline

**The automatic project manager and vulnerability auditor for everything around your code.**

## Short description

DriftCI keeps software releases aligned with reality after the review is over. It connects live GitHub pull requests and CI to official model, SDK, pricing and provider-status pages through Context.dev, then adds OSV and CISA KEV vulnerability intelligence. DriftCI maps relevant changes to repository code and exact PR heads, turns them into an evidence-backed work queue, and guides incident response with reachability clues, ordered checklists and Markdown records. A named reviewer records ready or hold for a precise commit, CI snapshot and evidence fingerprint; later changes expire that decision automatically. Teams spend less time coordinating releases and chasing advisories, while every next action remains linked to inspectable evidence.

## One-sentence pitch for judges

DriftCI automates the release coordination and vulnerability follow-up that happens around the code, while a named human keeps the ship decision.
